# ABC-анализ Капус / Студио — распродажа

Статичный сайт (один файл `index.html`, данные внутри). Сервер и сборка не нужны.

## Как выложить
1. Создайте на GitHub новый репозиторий (например `kapous-abc`) и загрузите в него файлы из этой папки (`index.html`, `render.yaml`, `README.md`) — кнопка **Add file → Upload files**.
2. На Render: **New → Static Site** → выберите репозиторий.
   - Build Command: оставить пустым
   - Publish Directory: `.`
3. Нажмите **Create Static Site** — через минуту сайт будет доступен по ссылке `*.onrender.com`.

## Как обновить данные
Пришлите новые выгрузки (CRM, остатки, прайс) — пересоберу `index.html`; на GitHub замените файл, Render обновит сайт сам.

## Важно
Скидки и клиенты, которые вписываются вручную, сохраняются только в браузере того, кто вписал. Чтобы передать план агентам — вкладка «Мой план распродажи» → **Скачать CSV** (открывается в Excel).
